# 🧪 أداة تحليل نتائج الطلاب في العلوم والحياة

أداة احترافية للمعلمين لتحليل نتائج الطلاب - تدعم الصف الخامس والسادس - شعب أ، ب، ج

### المميزات:
- ✅ تدعم ملفات Excel (xlsx, xls, csv)
- ✅ تحويل تلقائي من أي مقياس (10، 20، 30، 40، 100) إلى من 100
- ✅ تصنيف: ضعيف <50، متوسط 50-60، مقبول 60-70، جيد 70-80، جيد جداً 80-90، ممتاز 90-100
- ✅ رسوم بيانية تنازلية من الممتاز للضعيف
- ✅ جدول طلاب بارز مع بحث وفلترة
- ✅ خطط علاجية مقترحة لكل فئة
- ✅ نظام حفظ مطور: يحفظ كل امتحان لوحده لنفس الشعبة (شهري أول، ثاني، نصفي، نهائي)
- ✅ مقارنة عبر الزمن وتتبع تطور الطالب
- ✅ يعمل بدون إنترنت، RTL عربي كامل

2. اختر مقياس العلامة (تلقائي أو من 10/20/40)
3. احفظ الامتحان باسم (شهري أول مثلاً)
4. ارفع امتحان ثاني لنفس الشعبة وقارن
