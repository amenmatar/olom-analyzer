# أداة تحليل نتائج العلوم والحياة - v6 النهائية

الرابط الرسمي: https://amenmatar.github.io/olom-analyzer/

## المميزات v6:
- جدول الطلاب بارز في أول تبويب
- الخطط العلاجية المفصلة لكل فئة (ضعيف 5 طلاب... ممتاز 15 طالب) مع مقترحات عملية
- تحليل تنازلي من الممتاز للضعيف
- يدعم مقياس العلامات: 10، 20، 30، 40، 100 تلقائياً
- نظام حفظ مطور: يحفظ كل امتحان لوحده (شهري أول، ثاني، نصفي، نهائي)
- اسم المدرسة والمبحث ظاهر في الهيدر وفي التصدير
- RTL عربي كامل
